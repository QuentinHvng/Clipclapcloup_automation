TikTok account

          Not connected
        

        

          Optional. You can use this app without it — cut your clips, send them to your phone and post them
          from the TikTok app like you normally would.
        

        

          Before you set this up: until TikTok reviews and approves your own developer app,
          everything posted through the API lands as private, visible only to you. That is TikTok's rule
          for unaudited apps, not a setting this app can change. Posting by hand has no such limit.
        

        

      


      

        
AI captions

        

          Optional. With an Anthropic API key, each clip gets a written caption instead of the default one built
          from the video title. It uses your own key and your own credits — a few clips cost a fraction of a cent.
